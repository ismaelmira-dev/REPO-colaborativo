# Formulario de Contacto Moderno

Este proyecto es una página web que muestra un **formulario de contacto moderno** diseñado con **HTML y CSS**. Incluye una interfaz más profesional con una sección informativa y un formulario para enviar mensajes.

## Descripción

La página está dividida en dos secciones principales:

- **Sección de información**: muestra datos de contacto como correo, teléfono y ubicación.
- **Formulario de contacto**: permite al usuario escribir su nombre, correo electrónico y un mensaje.

El diseño utiliza un estilo moderno con **colores degradados, sombras, animaciones en los campos del formulario y un diseño responsive** que se adapta a pantallas pequeñas.

## Tecnologías utilizadas

- **HTML5** para la estructura de la página.
- **CSS3** para el diseño visual, animaciones y diseño responsive.
- **Flexbox y Grid** para organizar los elementos.

## Características

- Diseño moderno con **gradientes**.
- Formulario con **labels animados**.
- Sección de información de contacto.
- **Responsive** para dispositivos móviles.
- Efectos visuales al interactuar con los campos y botones.

## Funcionamiento

1. El archivo `index.html` contiene la estructura de la página y del formulario.
2. El archivo `styles.css` se encarga de los estilos, colores, animaciones y diseño.
3. El formulario incluye validación básica usando el atributo `required`.

Actualmente el formulario **no está conectado a un backend**, por lo que el envío de mensajes es solo visual.

## Cómo usar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en cualquier navegador web.
